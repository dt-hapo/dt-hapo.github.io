MCP server

DitingAgent 作为 MCP server 提供 Trace 转换、有界取证工具、确定性校验和 HTML 报告。模型、推理循环和工具选择由宿主 Agent 提供；在有设备授权时，也可以查看屏幕、操作控件并抓取 HTrace。 DitingAgent is an MCP server for trace conversion, bounded inspection tools, deterministic validation, and HTML reports. The host agent owns the model, reasoning loop, and tool selection; with device authorisation, it can also inspect the screen, operate controls, and capture an HTrace.

两种入口：设备或 Trace。Two entry points: a device or a trace.

可以从设备现场开始，也可以从已有 HTrace 开始。两种入口进入同一套分析、校验和报告流程。 Start from a live device, or from an HTrace you already have. Both paths lead into the same analysis, validation, and reporting pipeline.

连接设备、操作界面并抓取 Trace。Connect a device, operate the UI, and capture a trace.

设备工具可以读取当前屏幕和控件树，执行 tap、swipe、key、text，再调用 hiprofiler 抓取带 ftrace 和可选 hiperf 的 Trace。抓取期间也能继续执行 UI 步骤。 Device tools read the current screen and control tree, perform tap, swipe, key, and text actions, then call hiprofiler to capture ftrace and optional hiperf data. UI steps can run during capture.

四类性能场景。Four performance scenarios.

同一个“慢”字，可能是启动、首帧反馈、业务完成或一簇掉帧。DitingAgent 先固定时间边界，再选择对应的取证工具。 “Slow” can mean launch, first feedback, business completion, or a cluster of dropped frames. DitingAgent fixes the interval first, then selects the matching evidence tools.

有效输入 → 第一帧包含有效视觉反馈。Valid input → the first frame with effective visual feedback.
