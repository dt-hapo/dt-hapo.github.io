安装 DitingAgent，
接入宿主 Agent。 Install DitingAgent
and connect a host agent.

前置条件Requirements

Node.js 18+

运行 npx diting-agents 入口。安装 Node.js ↗Runs the npx diting-agents entry. Install Node.js ↗

Python 3.12+

运行 DitingAgent 和数据库转换。首次运行会在缓存目录创建环境；uv 可选。Runs DitingAgent and database conversion. The first run creates a cached environment; uv is optional.

宿主 AgentHost agent

DeepSeek Harness、Claude Code、Codex 或其他宿主 Agent；模型由宿主提供。DeepSeek Harness, Claude Code, Codex, or another host agent. The host provides the model.

HarmonyOS device + hdc

设备抓取、截图和 UI 操作需要可连接设备或模拟器；hdc 可来自 DevEco Command Line Tools。Capture, screenshots, and UI actions need a reachable device or emulator; hdc can come from DevEco Command Line Tools.

Windows、macOS 和 Linux 都使用同一条 npx 命令；不需要全局安装。Windows, macOS, and Linux use the same npx entry; no global install is needed.

运行 npx 入口Run the npx entry

npx diting-agents@latest --version 首次会创建 Python 环境并安装运行依赖；不需要克隆仓库。 npx diting-agents@latest --version creates a Python environment and installs the runtime dependencies on first use. No repository clone is required.

terminal / bash 
npx diting-agents@latest --version

注册到 宿主Register with an host

setup --detect 先列出本机检测到的宿主，再选择对应客户端写入配置。支持 dsh、codex、claude_code、cursor、qwen_code、opencode、kimi、qoder、zcode、trae；--client generic 可输出 JSON。 setup --detect lists detected hosts, then writes the matching client config. Supported clients include dsh, codex, claude_code, cursor, qwen_code, opencode, kimi, qoder, zcode, and trae; --client generic prints JSON.

terminal / bash 
# detect hosts, then register the matching client
npx diting-agents@latest setup --detect
npx diting-agents@latest setup --client dsh --yes --allow-root ~/traces

# multiple hosts, or a generic JSON config
npx diting-agents@latest setup --client dsh --client codex --yes
npx diting-agents@latest setup --client generic

写入后重启宿主或重载宿主插件。移除托管块使用 setup --client dsh --uninstall --yes，其他配置保持不变。Restart the host or reload the host plugin after writing. Remove the managed block with setup --client dsh --uninstall --yes; other config is left unchanged.

可选：运行 npx diting-agents@latest install-skills --yes，把场景方法论和工作流 Skill 安装到共享的 ~/.agents/skills。Optional: run npx diting-agents@latest install-skills --yes to install scenario methodology and workflow skills into the shared ~/.agents/skills.

健康检查Health check

doctor 是只读检查，验证 Node.js/Python、运行依赖、启动命令、托管配置、技能安装和工作目录。需要设备时把 hdc 路径一起传入。 doctor is read-only and checks Node.js/Python, the runtime dependency, launcher, managed config, skill installation, and workspace. Pass the hdc path when using device tools.

terminal / bashdoctor
npx diting-agents@latest doctor
npx diting-agents@latest doctor --json

# with a device
npx diting-agents@latest doctor --hdc /path/to/hdc

调试启动（可选）Debug start (optional)

日常分析由宿主自动启动 server。只有在调试连接或自定义客户端时，才需要手动运行 stdio server；指定 workspace 和可读取的 Trace 根目录。 The host starts the server automatically for normal analysis. Use a manual stdio server only for connection debugging or a custom client; specify a workspace and readable trace roots.

terminal / bashstdio
npx diting-agents@latest mcp \
  --workspace .diting/sessions \
  --allow-root ~/traces

--allow-root 限制 open_trace 可读取的目录；省略表示不限制。单次结果默认内联 64KB，超出后保留 Evidence ID。--allow-root limits directories that open_trace can read; omitting it leaves the path unrestricted. Inline results default to 64KB; larger results stay available by Evidence ID.

设备工具Device tools

设备工具默认关闭，需要 --enable-device；共 11 个工具。先检查或安装 Command Line Tools，再注册带 hdc 的设备配置。开启后 act 会真实点击和滑动，capture_trace 会调用 hiprofiler。 Device tools are off by default and require --enable-device. Check or install Command Line Tools, then register a device-enabled config. Once enabled, act really taps and swipes, and capture_trace invokes hiprofiler.

terminal / bash 
npx diting-agents@latest env status
npx diting-agents@latest env install \
  --archive ~/Downloads/commandline-tools.zip --yes

npx diting-agents@latest setup --client dsh \
  --device --hdc /path/to/hdc --yes
npx diting-agents@latest doctor --hdc /path/to/hdc

npx diting-agents@latest mcp \
  --workspace .diting/sessions \
  --allow-root ~/traces \
  --enable-device --hdc /path/to/hdc
